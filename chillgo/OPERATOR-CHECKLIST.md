# ChillGo — Operator Checklist (phone-friendly)

Short, numbered, no open-ended asks. Everything the agent **can't** do because it
needs your accounts, money, or a live deploy. The agent has already built the
code and copy — see `README.md`.

## A. Before the sourcing script can run (Section 3)
1. [ ] Shopify account/trial active (skip if you already have one).
2. [ ] CJ Dropshipping account created.
3. [ ] In CJ → **API / Developer**: enable API access and generate an **API key**.
4. [ ] Send me the CJ email + API key (or set `CJ_EMAIL` / `CJ_API_KEY` yourself)
       so the sourcing script can authenticate.
5. [ ] Buy the domain: **chillgo.com** (fallback **galejet.com**) via INWX or
       Shopify. _(Spends money — your call.)_
6. [ ] Confirm PayPal Business works for the new store.

## B. After sourcing picks the product (I'll hand you the decision record)
7. [ ] Skim `sourcing/decision_record.md` — this is a report, not an approval gate.
8. [ ] Approve ordering **one sample unit** (~€15–20). _(Spends money.)_

## C. Store build (I do the code; you click a few app buttons)
9. [ ] Install the **CJ Dropshipping** app in Shopify; I'll import the product.
10. [ ] Pick + install a **reviews app** (Loox / Judge.me / Ali Reviews — check
        current App Store ratings first). I'll wire its block into the page.
11. [ ] Enable pixels via Shopify **Customer events** (Meta) + the **TikTok** app.
12. [ ] Set up the **cookie-consent banner** (required before any pixel fires).

## D. Go-live gates — I will STOP and ask before any of these (Section 13.8)
13. [ ] Publish the theme live.
14. [ ] Order the sample unit.
15. [ ] Spend any of the €50.

## E. Launch week
16. [ ] Order sample → film B-roll (see `marketing/tiktok-scripts.md`).
17. [ ] Post day-1 content; follow `marketing/week1-calendar.md`.
18. [ ] Watch the metrics in `week1-calendar.md`; pick the week-2 hook.

## €50 budget (Section 12)
- ~€15–20 sample unit · ~€10–15 domain · ~€15–20 buffer / small TikTok Promote.
